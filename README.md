# DeshiDokan

DeshiDokan is a frontend e-commerce web platform celebrating authentic Bangladeshi local crafts, heritage products, and regional district specialties.

Built purely with vanilla web standards:
- **HTML5**
- **CSS3**
- **Vanilla JavaScript**

---

## Project Structure

```text
DeshiDokan/
```
